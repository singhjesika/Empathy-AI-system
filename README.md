# 🤖 Empathy AI Assistant

Empathy AI is an intelligent conversational assistant developed using Python that focuses on emotional understanding and supportive interaction.

The system uses Natural Language Processing (NLP) and sentiment analysis to detect user emotions and conversation topics, enabling it to generate meaningful and context-aware responses.

It is designed to assist users in areas such as study guidance, stress management, and personal well-being.

## 🚀 Key Features

- 🧠 Sentiment Analysis using TextBlob
- 🧩 Topic Detection (Study, Stress, Health, General)
- 🎙️ Voice Interaction (Text-to-Speech using pyttsx3)
- 💬 Context-Aware Response Generation
- 📜 Conversation History Tracking
- 🔄 Real-Time User Interaction Loop

## 🛠️ Technologies Used

- Python
- TextBlob (NLP & Sentiment Analysis)
- pyttsx3 (Voice Assistant)
- Regex & Standard Python Libraries

## 🎯 Project Objective

To build an intelligent assistant capable of understanding human emotions and providing supportive, meaningful, and personalized responses in real time.

## 📌 Future Scope

- Machine Learning-based emotion classification
- Personalized recommendation system
- Mood prediction using historical data
- Integration with advanced LLMs
